# Assess Pull Request Review comments

Given a Github PR number or url, look at all the unresolved review comments on the PR and for
each comment, assess whether the comment identifies a valid issue / something
worth fixing, or whether the comment is invalid / not worth fixing.

Provide your concise reasoning so that a human can follow it who may not have 
necessarily read the code in detail.
